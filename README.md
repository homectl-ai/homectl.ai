# homectl.ai

The homectl.ai site (GitHub Pages) and the Go vanity import pages for `homectl.ai/homectl` and
`homectl.ai/homectl-net`. Pages needs the repo public on the free plan, or a paid plan for private repos.

## Logo
In `brand/`: `homectl-wordmark.svg` (follows light/dark), `logo.svg` (app icon), `favicon.svg`/`favicon.ico`,
`apple-touch-icon.png`, `logo-120.png` (for app consoles such as Google's consent screen) and `logo-512.png`.
