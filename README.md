# homectl.ai

The homectl.ai site (GitHub Pages) and the Go vanity import pages for `homectl.ai/homectl` and
`homectl.ai/homectl-net`. Pages needs the repo public on the free plan, or a paid plan for private repos.

## Logo
`homectl-wordmark.svg` (follows light/dark), `logo.svg` (icon), `logo-120.png` (for app consoles). Set in
[Bricolage Grotesque](https://github.com/ateliertriay/bricolage) ExtraBold (SIL OFL 1.1), the "o" a lit dot;
outlines, so no font is needed. Rebuilt with `build_logo.py <BricolageGrotesque variable .ttf> <out dir>` (fonttools).
